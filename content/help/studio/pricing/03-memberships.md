# Memberships

**Memberships** aren't available yet — this page is a placeholder for when they land.

The idea: where a **pass** sells a fixed number of credits (see **Pricing → Passes**), a **membership** would instead sell a recurring period of access — for example, unlimited classes for a flat monthly fee, billed automatically until cancelled. It's a different mental model from a pass, not just a bigger one, so it'll get its own setup flow rather than being another pass type.

Until it ships, a monthly-unlimited-style offer can be approximated with an auto-renewing, high-credit pass template — see **Pricing → Passes → Auto-renew**.
