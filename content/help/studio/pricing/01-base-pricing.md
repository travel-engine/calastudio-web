# Base pricing

Every session has its own drop-in price — what a member pays if they book without a pass or membership. This is the price shown by default on your booking page.

## Setting a price

1. Go to **Sessions** and open a session (or create a new one)
2. Under **Pricing**, set the **drop-in price** — the standard cost of a single booking
3. Click **Save**

Leave the price blank to make the session free to drop in.

## Currency

Prices are shown in your studio's currency, set when you onboarded. All sessions and pass templates in your studio use the same currency — CalaStudio doesn't currently support per-session currency overrides.

## How this interacts with passes

Drop-in pricing only applies when a member pays directly for a single booking. If they use a pass instead, the session is covered by a credit (or included, for an unlimited pass) rather than charged at the drop-in price. See **Pricing → Passes** for how to set up pass-based pricing.

## Restricting to pass/membership only

If you don't want members paying drop-in at all — for example, a members-only class — set the session's **Booking access** to **Restricted** so only specific passes or memberships can be used to book it. Restricted sessions can't be booked yet, by staff or members — this is still being built.

## Card payment isn't live yet

Right now, bookings can only be made with an existing pass or comped by staff (see **Managing bookings**) — paying the drop-in price by card isn't wired up yet, so setting a price here doesn't yet mean it can be charged.
