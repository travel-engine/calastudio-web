# Teacher roles

Every person you invite gets one role that controls what they can see and do in your studio's dashboard. Roles restrict what's fetched, not just what's shown — a role without access to member data never receives it, so there's nothing to accidentally leak.

## The roles

| Role | Sessions | Members | Financial data | Studio settings |
|---|---|---|---|---|
| **Admin** | All | All | Full | Full |
| **Super teacher** | All | All | Can issue passes and process bookings | None |
| **Teacher** | Own sessions only | Only their own sessions' rosters | None | None |
| **Basic teacher** | Own sessions only | Attendance marking only — no member details | None | None |
| **Front desk** | Full schedule (view only) | Check-in only | None | None |

## Choosing a role when inviting

Pick the narrowest role that lets someone do their job. A casual instructor covering the occasional class only needs **Basic teacher**; someone running their own program day-to-day needs **Teacher**; someone you'd trust to manage the studio in your absence needs **Super teacher**.

## Changing a role later

Open the person's profile from **Team** and update their role. Changes apply immediately — no need to re-invite them.

## Multiple roles at once

A person can hold more than one role — for example, a member who also teaches one class a week can be both a **Member** and a **Basic teacher**. See **Multiple roles** in *Inviting teachers* for how that works.
