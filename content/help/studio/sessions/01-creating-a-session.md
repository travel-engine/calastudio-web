# Creating a session

Sessions are the core of CalaStudio. Every class, workshop, or event you run is a session.

## Create a new session

1. From your dashboard, click **Sessions** in the sidebar
2. Click **+ New session**
3. Fill in the details and click **Create session**

## Required fields

| Field | Notes |
|-------|-------|
| Session name | Must be unique in your studio |
| Delivery mode | In-person or online |
| Duration | How long the session runs |
| First occurrence | The date and time of the very first class. For a recurring session, every later date is generated from this one — see **Recurring sessions** |

## Instructor

Assign a teacher as the session's instructor and it determines what they can see: Teacher and Basic teacher roles only see sessions (and their rosters) where they're the assigned instructor. Leave it **Unassigned** and no teacher-level role can see the session at all — only Admin, Super teacher, and Front desk can. See **Team → Teacher roles** for the full picture.

## Delivery modes

- **In-person** — members attend at your physical location
- **Online** — members join via a link (Zoom, Google Meet, etc.)

Each session has a single **capacity** and a single **price**, regardless of mode.

## Recurrence

Set a session as **recurring** to have it repeat on a schedule. Choose which days of the week it runs — for example, every Monday, Wednesday, and Friday — and optionally when it ends. See **Recurring sessions** for how that turns into actual bookable dates.

One-off sessions (like a special workshop) leave recurrence set to **One-off** — **First occurrence** is the only date it needs.

## Visibility

| Setting | What it means |
|---------|---------------|
| **Public** | Listed on your booking page |
| **Private** | Not listed — bookable via direct link only |
| **Draft** | Invisible everywhere while you're setting it up |

## Booking access

| Setting | What it means |
|---------|---------------|
| **Open** | Any pricing option works — pass, membership, or drop-in |
| **Free** | No payment required. Anyone can book. |
| **Restricted** | Only specific passes or memberships can be used |
