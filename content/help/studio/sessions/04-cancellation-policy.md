# Cancellation policy

Each session has a cancellation window — how many hours before it starts a member can still back out.

## How the window is decided

CalaStudio checks three places, in order, and uses the first one that's set:

1. An override on the specific occurrence (not yet editable from the dashboard)
2. The session's own **Cancellation window (hours)**, under **Settings**
3. Your studio-wide default, which is 12 hours unless changed by support — there's no settings screen for this yet

## Setting a session's window

1. Open the session and find **Cancellation window (hours)** under **Settings**
2. Enter the number of hours before the session starts that cancellations are allowed — for example, `12` means members can cancel up until 12 hours before the class
3. Save the session

Leave it blank to fall back to your studio's default rather than the session having its own cutoff.

## What happens to the credit

Cancelling **inside** the window returns any pass credit used immediately. Cancelling **outside** it (a "late cancel") is governed by a single studio-wide setting for whether late-cancelled credits are forfeited — there's no dashboard control for this yet, and it isn't set per pass template or per session.

A forfeited credit isn't necessarily gone for good — Admin and Super teacher can manually return it from the occurrence's **Cancelled** tab. See **Payments → Refunds**.

If the studio cancels the occurrence itself, every credit is returned regardless of the window — see **Managing bookings → Cancelling a whole occurrence**.
