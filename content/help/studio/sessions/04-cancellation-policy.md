# Cancellation policy

Your cancellation window is how many hours before a class starts a member can still cancel without losing anything.

## How the window is decided

CalaStudio checks two places, in order, and uses the first one that's set:

1. The session's own **Cancellation window (hours)**, under **Booking rules** on the session
2. Your studio-wide default, under **Settings → Booking policy**

## Setting your studio-wide default

1. Go to **Settings** and find the **Booking policy** card
2. Set **Cancellation window (hours)** — for example, `12` means members can cancel up until 12 hours before the class
3. Click **Save** on that card

The same card holds your other studio-wide booking rules: **Booking closes (hours before)**, **Book up to (days ahead)**, and whether late cancellations forfeit the credit (below).

## Giving one session its own window

1. Open the session and find **Cancellation window (hours)** under **Booking rules**
2. Enter the number of hours
3. Save the session

Leave it blank to use your studio default instead.

## What happens to the credit

Cancelling **inside** the window returns any pass credit used immediately. Cancelling **outside** it is a "late cancel": whether the credit is lost is set by the **Late cancellations forfeit the pass credit** switch in **Settings → Booking policy**. It's studio-wide — not set per pass or per session.

A forfeited credit isn't necessarily gone for good — Admin and Super teacher can manually return it from the class's **Cancelled** tab. See **Payments → Refunds**.

If the studio cancels the class itself, every credit is returned regardless of the window — see **Managing bookings → Cancelling a whole class**.
