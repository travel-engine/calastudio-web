# Cancellation policy

Each session has a cancellation window — how many hours before it starts a member can still back out.

## Setting the window

1. Open the session and find **Cancellation window (hours)** under **Settings**
2. Enter the number of hours before the session starts that cancellations are allowed — for example, `12` means members can cancel up until 12 hours before the class
3. Save the session

Leave it blank if you don't want to enforce a cutoff.

## How it works with passes

Whether a credit is returned to a member's pass when they cancel in time is controlled separately, on the **pass template** — see **Pricing → Passes → Optional settings → Credit return on cancel**. The session's cancellation window sets the *deadline*; the pass template decides what happens to the credit once that deadline has (or hasn't) passed.

## Setting a studio-wide default

There's no org-wide default cancellation window yet — it's set per session. If most of your classes share the same policy, it's easiest to set it once and use **Copy** when creating similar sessions so the setting carries over.
